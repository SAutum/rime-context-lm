# rime-context-lm

Experiment: replace/augment Rime Octagram's contextual language-model score with a neural Chinese language-model score while keeping Rime responsible for pinyin parsing, dictionary lookup, candidate generation and user interaction.

## Goal

Given:

- committed Chinese context `C`
- current pinyin `P`
- candidates generated by Rime `{c1, c2, ...}`

compare contextual ranking methods without changing the candidate set.

The first experiment compares:

1. **Rime / Octagram** — existing contextual grammar baseline.
2. **Neural conditional score** — rank by `log P(candidate | context)`.
3. **Neural context gain** — rank by `log P(candidate | context) - log P(candidate)` to measure how strongly the context supports a candidate rather than merely rewarding globally frequent words.

No RL, no text generation, and no replacement of Rime's pinyin decoder in this phase.

## Quick start

Python 3.10+ is recommended.

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
python -m benchmark.run
```

The default model is configurable through `RIME_CONTEXT_LM_MODEL`. The initial default is `uer/gpt2-chinese-cluecorpussmall` because it gives us a simple, public Chinese GPT-style baseline. It is **not** assumed to be the final model.

To start the experimental scorer API:

```bash
uvicorn scorer.server:app --host 127.0.0.1 --port 8765
```

Example request:

```json
{
  "context": "我今天身体不舒服准备去",
  "pinyin": "yiyuan",
  "candidates": ["医院", "意愿", "一元", "议员"]
}
```

## Phase 1 success criterion

Before integrating deeply into Weasel/librime, prove one thing offline:

> With exactly the same Rime candidate set, can a small neural Chinese LM rank the intended candidate above Octagram more often, at acceptable latency?

Only after that result is positive do we optimize inference and wire the scorer into the live Rime candidate pipeline.

## Reference

Primary historical baseline paper:

- Wang et al., **Investigating Chinese Pinyin Input Method in the Age of Neural Language Models**, ACL 2022. https://aclanthology.org/2022.acl-long.133/

That paper motivates GPT-style Chinese language modeling for Pinyin IME. This repository narrows the problem: Rime keeps doing decoding and the neural model is initially used only as a contextual candidate scorer.
